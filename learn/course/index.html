课程安排

学习流程、通过条件，以及一节课的热身、专项、主项和放松。

各式的阶段和专项见 自由泳、仰泳、蝶泳、蛙泳。上课口令在各册的课堂教学里。四泳姿页只留通用路径和连贯口令。入水共同课见 USMS 汇总。

这里只写四式共用的安排。某一式卡在哪一阶段、用哪一句口令、做哪一个专项，到该式自己的册子里查。

学习流程

按这一序走，不按已经游过的距离升级：

1. 定阶段。 看该式最弱的一环。能游很远，但腿、换气或配合仍明显不对，阶段就停在那一环。

2. 看现象。 只写一个看得见的问题，例如抬头、剪刀腿、一换气动作就散。

3. 选一个专项。 只针对这一个现象，短距离做。

4. 回到完整泳姿复测。 原来的现象有没有减少。分解练得很像、完整泳姿一游就消失，这一课不算通过。

5. 巩固、进阶或退阶。 现象还在，就留在这一阶段，不进入下一个模块。

还不会呼气、漂浮和回站，先上入水共同课，不在某一式里教新动作。出发、转身和长距离水下不放进初学课的主项。

通过条件

一个阶段要同时满足下面四项，不能只看游完了多少米：

  • 可重复。 同一动作至少连续完成 3 次或 3 组。
  • 可控制。 能较慢、较放松地完成，不靠憋气、冲刺、拼命打腿或大幅度代偿。
  • 没有明显新代偿。 为了做成这一步，又冒出另一个明显错误，不算通过。
  • 能带回完整泳姿。 专项里的改进，在完整的这一式里还在。

左右都要会的动作，两侧都过才算过。动作一开始明显变形，就结束这一趟，退回上一个分解，不用错误动作把距离游完。

一节课

一节课只处理一个主要现象。时间不够时，先保证专项和主项，热身和放松缩短，不把两个新动作塞进同一节。

热身

入水后用已经会的轻松动作活动，确认呼吸顺、能漂、能自己结束。热身不教新动作。身体热了、气顺了就停。

专项练习

从该式册子里选一个对应当天现象的练习。短距离，做数组，只留一个提示。这一段看的是动作有没有被做出来，不把专项本身的好看当成学会。

自由泳的专项在自由泳册的卡片里选。仰泳、蝶泳、蛙泳的专项在各册的列表里选。

主项练习

马上游完整的这一式。先带着刚才那一个提示游，再去掉提示游一次。比较原来的现象还在不在、是不是更费力、动作有没有散。现象还在，下一节水仍停在这个阶段。

放松

用更慢、更熟的动作把呼吸和肩颈放松下来。在浅水确认能自己站稳或靠岸，再离开。放松不再加一组技术，也不再测新动作。

各册各看什么

  • 课程安排：流程、通过条件、一节课的四段。
  • 自由泳、仰泳、蝶泳、蛙泳：这一式的阶段、现象、专项，以及课堂教学的口令、纠错和要点。
  • 四泳姿：四式共用的学习路径和每个模块的连贯口令。
  • 汇总：入水共同课，以及动作和训练的依据。
  • 自救：意外入水之后怎么停留和离开。不放进技术课的主项。

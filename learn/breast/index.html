蛙泳学习体系

用来定阶段、看现象、选一个专项，再按课堂教学的口令上课。

四式阶段诊断：自由泳 · 仰泳 · 蝶泳 · 蛙泳。课堂教学（口令、纠错、要点）在本册下文。入水共同课见 USMS 汇总。一节课怎么排见 课程安排。个人自救见 水中自救。

本册用来判断蛙泳卡在哪一阶段、看到什么现象、选哪一个专项，然后回到完整蛙泳复测。上课时的口令和从陆上到水中的步骤，用四泳姿教学里的蛙泳模块。

入水、呼气、漂浮和回站是四式共用前提，不在蛙泳课里重教。出发、转身和水下出水等表面蛙泳稳定之后再单独学。

课堂教学：口令、纠错与要点

从陆上到水中按口诀与练习走；看见的现象到分类纠错里核对；动作原理看技术要点。一节课只取其中一个模块。

蛙泳腿

收腿、翻脚、蹬夹、滑行，四个环节不遗漏。

检查与适用提示

检查后方看双脚同收同翻同蹬，侧面看大腿不过度抱腹；蹬后并腿伸长且不痛。脚尖角度依活动条件，不强扭膝。

取舍无适合池边承托时直接扶壁练；不硬扭膝脚。

蛙泳手与呼吸

外划找水，抱水吸气，前伸回水，水下呼气。

检查与适用提示

检查分解到连贯都遵循同一事件顺序；取气不依赖猛仰颈、出水后无长停，通气舒适。吸气可横跨相邻阶段，不锁死某一帧。

取舍按嘴出水取气、前伸回水的事件衔接，不机械固定某一瞬间。

蛙泳完整配合

手先有效划，前伸时收翻，后蹬夹拢，恢复流线型。

检查与适用提示

检查两段主要推进有序，回臂/收腿紧凑，蹬后能并腿回线；呼吸不拖动作。每次滑行随速度而变，不强制三秒。

教练怎么用

一堂课只处理一个主要现象。能游很远但仍是剪刀腿、全程抬头或手脚同时蹬，阶段仍停在腿或配合，不按距离升级。

诊断阶段四泳姿模块上课口令
M0～M1 适应与流线不在蛙泳课重开先完成入水共同课。流线只要求头在双臂之间，不仰头。
M2 蛙泳腿蛙泳腿脚跟回收，勾脚外翻；向后蹬夹，并腿伸长；动作连贯，不漏翻脚。
M3 划臂与换气蛙泳手，然后手与呼吸外划找水，抱水内收，快速前伸。抱水起胸短吸；手前伸、头回水。
M4～M5 配合与稳定蛙泳完整配合抱水短吸，前伸收翻；后蹬夹拢，伸长后接下一划。
M6 效率平蛙进阶低位吸气，快速前伸；紧凑收翻，后蹬恢复平直。
稳定之后的起伏波蛙进阶抱水前起短吸，手前送、头回水。还在剪刀腿或抬头换气时不上这一课。
M7 转身与速度不进初学主线表面蛙泳稳定后再学双手触壁和转身。

不要把「慢收快蹬」当成口令。脚跟要及时回收并翻脚，再加速向后蹬夹。收得过慢，大腿迎水更久。翻脚不能省，也不为了翻脚去扭痛的膝盖。

滑行没有固定秒数。速度还在、身体尚未停住时接下一划。平蛙是把无效起伏收小，不是要求身体完全不动。波蛙允许适度起伏，不额外加一次蝶泳腿当作蛙泳周期。

蛙泳不应只按“先学腿、再学手、最后配合”粗略划分，而应按最弱子系统判断阶段。有人能连续游几百米，但仍然是剪刀腿、全程抬头或手脚同时发力，其技术阶段实际上仍停留在基础阶段。蛙泳具有推进阶段不连续、周期内速度波动大、肢体回收阻力明显等特点，因此多数问题并不是“力量不够”，而是推进方向、身体姿态、回收阻力和动作时序出了问题。Springer

一、先统一“现象—问题—原因—影响—练习”的关系

诊断时必须把五个对象分开：

  • 现象：摄像机能直接看到什么，例如“吸气后头突然向下砸”。
  • 技术问题：动作之间哪里不合理，例如“头部主动下压，没有随肩膀和手臂前伸自然回位”。
  • 根因：为什么会这样，例如吸气过晚、上身抬得过高、手停在胸前、把“低头入水”理解成主动扎头。
  • 影响：造成什么后果，例如增大迎水面积、身体向下钻、蹬腿时尚未形成流线。
  • 专项练习：通过限制条件重新建立正确动作，并且必须回到完整蛙泳复测。

一个现象通常对应多个可能原因；一个根因也可能制造多个现象。因此专项练习应针对“问题或根因”，而不是只针对表面现象。

“头猛扎回水”的完整诊断示例

可见现象：嘴完成吸气后，下巴或额头突然向下，水花较大；双手可能在胸前停顿或向斜下方伸；上身向下钻、臀部上浮，身体像跷跷板；蹬腿开始时手臂尚未充分前伸。

技术问题：头颈、肩胸和手臂没有作为一个整体向前回到流线，动作主要发生在垂直方向，而不是向前。

常见根因：

  1. 吸气过晚，手已经开始前伸，头还留在水面；
  2. 为了把嘴抬出水面，主动仰头或压水抬头，上身抬得过高；
  3. 双手内划后停在胸前，失去向前牵引；
  4. 把“头先回水”误解成“用力低头扎水”；
  5. 蹬腿过早，身体尚未伸直便开始发力。

影响：增加垂直起伏和正面阻力；破坏流线；使蹬腿推进被倾斜身体抵消；增加颈部负担；容易形成“抬得越高—扎得越深”的恶性循环。

纠正目标：吸气应在内划阶段快速完成；随后双手立即向前射出，肩胸下降，头保持颈椎中立并随肩膀一起回位。正确动作可以很快，但不应是头部单独向下砸。

复测标准：侧面视频中头、肩和双手基本朝同一条向前路径运动；入水水花较小；手臂接近伸直后才出现主要蹬腿推进；蹬腿结束时头、躯干、髋和腿形成一条较长的流线。

二、完整动作链：诊断要找“最早出现的偏差”

基础蛙泳的动作顺序可以概括为：

伸直滑行 → 双手外划建立支撑、肩胸自然上升 → 双手内划并快速吸气，同时脚跟向臀部回收 → 双手迅速前伸、头随肩胸回到中立 → 双脚形成迎水面并向后蹬夹 → 双腿并拢伸直、全身流线滑行 → 下一次划臂。

需要特别区分：

  • “收腿”主要是把脚跟回收到臀部方向，不是把双膝顶向胸口；
  • 腿可以在划臂后段开始回收，但真正向后蹬水应等手臂接近前伸；
  • 头可以快速回水，但应当随肩胸和手臂回位，而不是主动扎下去；
  • 滑行时间没有固定的“两秒或三秒”。速度越高，滑行一般越短；轻松游时可以稍长，但不应等身体完全停住才开始下一划。不同距离和速度下，划频、划幅、推进时间和滑行时间都会变化。Springer

动作姿态的基本方向是：滑行时头部与躯干保持一致，身体接近水平；划臂不宜过宽、过深或拉到腰部；收腿时脚跟靠近臀部而不是膝盖靠近胸部；脚部形成迎水面后向后蹬夹，最后双腿并拢伸直。

三、蛙泳学习的八个阶段与里程碑

下列距离和重复次数是便于教学管理的操作性标准，不是所有人的统一生理标准。正式游泳教学体系也通常采用“10米蛙腿—10米完整蛙泳—有节奏换气—25米规范游—较长距离保持质量—同等时间减少划次或同等划次提高速度”的递进方式。

阶段核心任务建议通过里程碑常见卡点优先专项
M0 水中适应与安全入水、浸脸、呼气、漂浮、恢复站立能舒适浸脸并连续呼气3—6秒；俯漂和仰漂后独立站起；蹬壁流线滑行约3—5米憋气、抬头、慌乱、手脚乱动水下连续呼气、漂浮转站立、箭形滑行

M3 划臂与换气用划臂和肩胸上升完成低幅、快速吸气连续完成至少6次有节奏换气；不靠仰头或压水抬头；双手不拉到腰部；前伸无明显停顿手臂过宽、向下压水、吸气过晚、头留在水面小心形划臂、低换气、快速前伸
M4 基础配合建立“一次划臂—一次蹬腿—一次流线”的顺序15—25米内保持一划一蹬；每周期一次呼吸；蹬腿时手臂已接近前伸；能看到划臂和蹬腿带来的两段加速手脚同时发力、蹬腿太早、头回位太晚、无滑行或过度滑行一划一蹬一滑、延迟蹬腿、口令配合
M5 稳定且规范的完整蛙泳动作可重复，不靠临时提醒维持4×25米中无剪刀腿、交替动作等明显错误；划次相差不超过约2次；同强度时间差不超过约10%；能双手同时触壁前半程正常、后半程动作散；左右不对称；触壁随意视频复测、划次控制、双手触壁
M6 效率与耐力在疲劳前提下维持姿态、节奏和推进效率连续100米或4×50米后仍保持动作；最后25米划次增幅不超过约10%—15%；能在相同划次下游得更快，或相同速度下减少划次越游越急、头越来越高、膝越来越宽、滑行消失划次—时间联合训练、短间歇技术组
M7 速度、转身与专项分支根据比赛、长距离或开放水域目标调整能改变划频而不破坏技术；完成规范转身、出发后水下动作和出水衔接；长距离中能稳定切换节奏追求高频导致动作缩短；出水与第一周期断开；转身触壁不规范节奏器训练、触壁转身、出水衔接

阶段按最弱环节确定。例如，能游200米但仍有明显剪刀腿，应当回到M2；单独腿和单独手都正确，但完整配合明显变慢，主要问题属于M4，而不是继续加强腿力。

截至2026年2月，竞技蛙泳的核心规则仍包括：身体保持俯卧；手臂和腿分别同时运动而不能交替；正常周期为一次划臂后接一次蹬腿；蹬腿推进阶段双脚需向外形成蛙泳腿；每个完整周期头部需露出水面；转身和到边需双手分开并同时触壁。休闲学习者不一定参加比赛，但这些要求可以作为对称性和动作顺序的检查标准。

四、最快的定位流程

不要直接看完整蛙泳猜原因，应按以下顺序拆分：

1. 先排除疼痛和恐水：膝、髋、颈、腰出现明显疼痛时，不能用“多练几组”解决。

2. 测试10米蛙泳腿：若蹬腿没有清晰加速，先处理脚部迎水面、蹬水方向和左右对称。

3. 测试短距离划臂换气：腿部放松或使用浮力辅助，观察是否过度抬头、压水、停手或吸气过晚。

4. 测试完整配合：单项都正常、合起来变差，优先判定为时序问题。

5. 分别测试方向：蛙腿单项就偏，主要查腿；划臂单项偏，主要查手臂、头部或肩部。

6. 比较前后半程：开始正常、疲劳后才出现，说明技术尚未稳定或用力过大，不等于动作完全不会。

视频最好至少包含：侧面水上、侧面水下、正面或后方水下三个视角。侧面适合看头部、身体角度和配合；后方适合看膝、脚和左右对称；正面适合看划臂宽度和身体偏转。

五、身体姿态与呼吸的常见现象

直接可见的现象首要定位与可能根因主要影响专项练习与复测
滑行时一直看前方，下巴抬起，臀腿逐渐沉下去颈部后仰、担心水进脸、没有建立头部中立位；若姿态正确仍缓慢下沉，也可能只是个体浮力差异正面阻力增大；蹬腿容易变成向下蹬D1箭形滑行；眼睛看池底前方，耳朵靠近双臂。侧面复测头—躯干是否连续

九、专项练习动作库

D0 水下连续呼气

浅水站立，水面上自然吸气，面部入水后连续、均匀呼气3—6秒，再站起。完成6—8次。目标不是憋气时间，而是消除“出水后才吐气”。

D1 箭形蹬壁滑行

双手重叠或并拢前伸，头位于双臂之间，蹬壁后不划不蹬，轻微呼气滑行3—5米。完成6次。重点观察是否仰头、耸肩、屈髋或双腿分开。

D2 小划臂低换气

腿部放松，必要时短距离使用浮漂。双手做较小的外划和内划，肩胸只上升到嘴刚好离水；快速吸气后，双手与头一起向前回位。6×5—10米。浮漂只用于短距离隔离问题，不能长期替代完整配合。

D3 陆上四拍蛙腿

低速练习“收脚—翻脚—向后蹬夹—并腿伸直”，2×8次。陆上只用于理解顺序，不用追求很大的脚外翻角度，更不能从膝关节强扭。

D4 扶壁收脚—翻脚—蹬夹

双手扶池边，身体尽量水平。脚跟向臀部回收，勾脚外翻，再向后加速蹬夹，并腿伸直。2×8次。不要把收腿故意拖得很慢，大腿迎水越久，蹬腿前掉速越多。

D5 仰卧蛙泳腿

仰卧，双臂置于体侧或前伸。收脚时尽量不让双膝明显冲出水面，观察左右膝、脚和结束位置是否同步。6×10米。它适合发现膝盖顶胸、剪刀腿和结束不并腿。

D6 俯卧流线蛙泳腿

双臂前伸、脸入水，每次只做完整的一次收脚、蹬夹和并直。可使用小浮板，但不建议用大浮板长期抬头练习。6×5—10米。

D7 单腿路径校准

扶壁或仰卧低强度练习，一条腿保持伸直，另一条腿缓慢完成收脚、形成迎水面、向后蹬夹，左右各2×6次，再恢复双腿同步。它主要用于诊断和重建路径，不用于大力训练；出现膝痛立即停止。

D8 小心形划臂

从流线开始，双手略向外划至肩宽附近，前臂建立向后迎水面，随后双手向内汇合至上胸或下巴前，再立即向前伸。6×5—10米。避免拉到腰边。

D9 窄通道快速前伸

双手内划汇合后，像穿过一条狭窄通道一样立即向前射出；头和肩随之回位，手臂不向下钻。6×10米。适合处理胸前停手、头猛扎和回收阻力过大。

D10 一划一蹬一滑

使用统一口令：

划—吸—伸—蹬—直/滑。

先做6×10—15米，再做4×25米完整蛙泳。教学初期可以在“直/滑”处停一拍，但随后要逐步过渡到自然节奏。

D11 延迟蹬腿

脚跟可以在划臂后半程回收，但双脚真正开始向后蹬时，双手应已经通过额头并接近完全前伸。6×10米。严重蹬腿过早者可以短暂使用“一次划臂、两次蹬腿”感受第二次流线蹬腿，但练习后必须立即恢复合法的一划一蹬，避免形成新习惯。

D12 划次—时间联合训练

连续完成6×25米，记录每趟时间和完整周期数。不能只追求划次少：

  • 时间相近而划次减少，说明每周期推进改善；
  • 划次相近而时间缩短，说明节奏或推进改善；
  • 划次减少但时间明显变慢，通常是滑行过长；
  • 划次快速增加而时间仍变慢，通常是技术在疲劳下崩解。

划次应主要与自己比较，不宜直接与身高、体型和技术风格不同的人比较。

D13 双手触壁与转身

从距离池壁3—5米处开始，完成最后一个周期，两手分开并同时触壁；随后收腿、转体、双手前伸、双脚蹬壁进入流线。重复8—12次。竞技水下出水动作应单独训练，并避免独自进行长时间水下闭气。

十、单次技术训练的标准结构

一次训练只选一个主要问题，最多附带一个次要提示：

1. 基线记录：2×25米完整蛙泳，记录视频、时间和周期数。

2. 隔离动作：选择1—2个专项练习，完成约6×5—10米。

3. 限制条件配合：用D10或D11完成4—6×10—15米。

4. 回到完整蛙泳：4×25米，只保留一个动作提示。

5. 无提示复测：2×25米，比较原现象是否减少，时间和划次是否恶化。

6. 里程碑判定：四次中至少三次达到标准，并在下一次训练中仍能复现，才算真正通过；不能只依据某一次偶然做对。

技术错误一旦在疲劳中持续出现，应缩短距离或增加休息，而不是用错误动作继续堆积游量。

十一、M5以后应按目标分支

健身和长距离蛙泳：重点是低幅换气、完整流线、不过度滑行、舒适呼气和稳定划次。不能把竞技短冲的高划频直接复制到长距离。

开放水域和自救：正常面部入水蛙泳作为主要前进方式，间歇加入抬头观察；另外独立学习仰漂、踩水、侧泳和姿态转换。全程抬头蛙可以用于短时观察，但不适合作为长距离唯一技术。

核对之后要改的教法

USMS公开资料并不是一套固定的“第一课学腿、第二课学手”的单线蛙泳课程，而是由三个层次组成：第一层是成人学游泳项目ALTS，重点是水中安全、基础游进能力和成人教学方法；第二层是蛙泳完整指南，按划臂、蹬腿、身体姿态、配合时序四个系统组织；第三层是从“会游”进入健身训练、技术改进和Masters团队训练的桥接内容。USMS蛙泳指南的四个系统，每个系统均配置6篇技术文章、10个渐进练习、5套训练组和10个陆上练习，并允许学习者从具体弱项进入，不要求所有人遵循唯一顺序。ALTS认证课程的基础目标则是帮助成人至少游完25码，并提高水中安全能力。

内划手掌和前臂共同向后、向内压水，双手在胸前或下巴前汇合拉到肋部、腹部甚至腰部；肘部落到身体后方
前伸回收双手汇合后立即向前送出，不能停在胸前前伸缓慢、手在胸口停顿、双手向斜下方钻水

USMS将划臂描述为相对短的推进动作：手和前臂应共同工作，划臂不应像自由泳一样拉到髋部；双手完成内划后，需要快速向前回伸，因为缓慢回收会延长肢体在水下向前运动的时间，增加阻力。

适合图片的核心口令：

小幅外划—前臂压水—双手汇合—立即前伸

2. 蹬腿系统 Kick

USMS对蛙泳腿的描述比“收、翻、蹬、夹”更强调两个方面：脚形成有效迎水面和主要向后推水。

动作阶段技术要求直接观察点
收脚脚跟快速靠近臀部，大腿不过度向腹部收膝盖不能大幅顶向胸口
翻脚准备脚踝背屈、脚尖转向外侧，双脚通常比双膝更宽脚掌内侧和脚底能朝向后方
向后蹬夹主要向后推动水，而不是画一个很大的水平圆圈蹬腿后身体是否立即加速
并腿伸直双腿合拢、膝盖伸直、脚尖重新延伸蹬完后双脚不能继续分开

USMS明确指出，蛙泳腿的主要推进方向是向后，而不是只做“向外—绕圈—夹腿”。脚的内侧、脚底和部分小腿共同形成迎水面；关键不是追求统一的膝宽，而是保证双脚能够翻出、位于双膝外侧并持续向后压水。个人髋、膝和踝活动度不同，动作宽度也会不同。

原有“慢收快蹬”建议改为：

脚跟快收，翻脚到位，向后加速蹬夹，最后并直。

这比“慢收”更符合USMS对快速腿部回收和充分准备的要求。美国大师游泳

3. 身体姿态系统 Body Position

身体姿态不是只在M1学习一次，而是贯穿划臂、换气、蹬腿和滑行的控制变量。

USMS的核心要求是：每个周期都要回到接近水平、伸展的身体线条。蛙泳允许适度的肩胸和髋部起伏，但起伏必须服务于呼吸和回到流线，不能形成持续的“抬头—下钻—再抬头”。由于双臂和双腿都要在水下向前回收，蛙泳本身阻力已经较大，身体姿态的小偏差就可能造成明显速度损失。

建议用三个检查点：

1. 吸气时：嘴刚好离水即可，不追求整个胸部高高抬起。

2. 前伸时：头、肩和双手一起向前回位，不是头单独扎下去。

3. 蹬腿结束时：头、躯干、髋和双腿恢复成一条长线。

4. 配合时序系统 Timing

USMS将时序视为独立系统，因为相同的划臂和蹬腿动作，在错误时机发生，仍会造成低效率。

基础动作链建议统一写为：

腿伸直时划臂 → 内划换气并开始收脚 → 双手快速前伸 → 手臂接近伸直时向后蹬夹 → 全身伸直利用速度 → 下一次划臂

需要区分三个时间点：

  • 收脚开始：可以在内划后段至双手前伸初段开始；
  • 蹬腿开始：应等上半身接近前伸位置；
  • 下一次划臂开始：应等当前蹬腿基本完成，并利用一段有效前进速度。

USMS还强调，50、100和200蛙泳所需时序并不相同：距离越短，动作间停顿通常越少、划频越高；距离越长，需要更重视每周期效率和疲劳管理。

六、USMS式训练路线：隔离—过渡—完整—量化

USMS的训练组通常不是一直重复同一专项动作，而是使用以下闭环：

建立动作感觉 → 隔离弱项 → 加入一部分完整动作 → 完整蛙泳 → 改变划次或速度 → 再次评估

例如，腿部训练会从垂直蛙泳腿或扶墙蛙泳腿开始，进入仰卧蛙泳腿和扶板蛙泳腿，再通过三蹬一划、两蹬一划逐渐加入划臂，最后回到完整蛙泳。划臂训练也会从前臂压水、夹浮漂划臂开始，再经过三划一蹬、两划一蹬，最后回到完整动作。

成人初学技术课模板

1. 基线：2×25米完整蛙泳，记录视频、划次和用时。

2. 动作感觉：选择1个低难度反馈练习，4×10—15米。

3. 隔离弱项：选择1个腿、手或身体姿态练习，4×15—25米。

4. 过渡配合：三蹬一划、两蹬一划或分离式蛙泳，4×25米。

5. 完整泳迁移：4×25米完整蛙泳，只保留一个动作提示。

6. 量化复测：2×25米，比较原现象、划次和用时。

效率训练模板

  • 2×25米建立正常划次；
  • 2×25米在用时接近的情况下少划一次；
  • 2×25米保持原划次但提高速度；
  • 2×25米自由选择最稳定组合；
  • 比较哪一种组合能够同时保持技术和速度。

USMS并不把最低划次本身视为最终目标，而是让学习者在不同划次下观察速度、用力程度和时序变化。

速度与耐力训练原则

速度训练应采用较短距离和足够休息，使学习者能够在较高速度下仍保持动作质量；耐力训练则可以将划臂、蹬腿分开训练，或大量使用25米、50米短重复，以避免长距离中技术持续崩解。美国大师游泳

七、USMS相关常见问答

问题回答
1. USMS是否有唯一的蛙泳学习顺序？没有公开的唯一线性课纲。完整指南按四系统组织，可从弱项进入；本文路线是结合ALTS、完整指南和Bridge to Masters重排的成人路线。
2. 成人初学一定要先学蛙泳吗？不一定。USMS将蛙泳描述为四种泳姿中技术结构较复杂的一种；ALTS首先关注安全和基本游进能力，而不是要求蛙泳必须成为第一种泳姿。
3. 应该先学腿还是先学手？对多数成人，可先建立流线和蛙泳腿，因为蛙泳腿通常承担更多推进；但如果学习者腿部已能推进、问题集中在换气或划臂，则应直接从相应弱项进入。
4. 手和腿完全不能同时动吗？不是。脚跟回收可以与内划后段和双手前伸有所重叠；错误是双手尚未回到前方，双脚已经开始主要的向后蹬水。
5. 为什么不再建议简单说“慢收快蹬”？USMS更强调快速回收脚跟、充分翻脚和加速蹬夹。过慢收腿会延长大腿迎水时间，增加阻力。
6. 双膝应该张多宽？没有统一厘米数。关键是脚能够翻出并位于双膝外侧，主要向后推水，同时动作不引发膝痛。
7. 蛙泳必须滑行几秒？没有固定秒数。应利用蹬腿后的速度，在速度明显下降但尚未接近停止前进入下一周期。
8. 划次越少是否代表技术越好？不一定。必须同时看用时。减少划次但用时明显增加，通常表示滑行过长。
9. 全程抬头蛙泳为什么会出现在USMS练习中？它是用于放大沉髋和高头位影响的对比练习，不是目标技术。
10. 三蹬一划、两蹬一划是正常蛙泳吗？不是。它们是用于强化腿部和流线的专项练习，练后必须恢复一划一蹬。
11. 蛙手配自由泳腿和蝶泳腿有什么区别？自由泳腿更适合稳定髋位、促进双手连续前伸；蝶泳腿更适合体验肩胸回位和髋部轻微起伏。
12. 水下蛙泳是不是越远越好？不是。USMS把它作为时序反馈练习；大众练习应限于少量舒适周期，不能作为憋气距离挑战。
13. 膝间夹浮漂蛙泳腿适合初学者吗？通常不适合作为基础大量练习。USMS明确提醒它会增加膝部压力，应慢速、短距离、以技术为目的。
14. 为什么快游时动作会散？蛙泳的时序会随速度改变。学习者若只在慢速下练过，快速时前伸、收脚和蹬腿的衔接往往跟不上。

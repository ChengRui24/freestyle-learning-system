蝶泳学习体系

用来定阶段、看现象、选一个专项，再按课堂教学的口令上课。

四式阶段诊断：自由泳 · 仰泳 · 蝶泳 · 蛙泳。课堂教学（口令、纠错、要点）在本册下文。入水共同课见 USMS 汇总。一节课怎么排见 课程安排。个人自救见 水中自救。

本册用来判断蝶泳卡在哪一阶段、看到什么现象、选哪一个专项，然后回到完整蝶泳复测。上课时的口令和从陆上到水中的步骤，用四泳姿教学里的蝶泳模块，不在本册另写一套课堂口令。

蝶泳不作为第一种入水泳姿。脸还不敢入水、不会漂浮或不会回站的人，先回入水共同课。出发、转身和长距离水下蝶泳腿不进本册初学主线。

课堂教学：口令、纠错与要点

从陆上到水中按口诀与练习走；看见的现象到分类纠错里核对；动作原理看技术要点。一节课只取其中一个模块。

口诀与练习

蝶泳

蝶泳身体波动

波由躯干经髋腿传向脚；身体向前，不向深处扎。

检查与适用提示

检查水中身体以向前为主，胸髋顺次联动、头不甩动，无腰痛；不以波浪越大越合格。

取舍池边悬胸不作默认练法；扶壁限制肩胸时跳过。

蝶泳腿

双腿同时上摆、同时下打；髋带腿，脚背接鞭。

检查与适用提示

检查可见两腿同步往返；膝自然屈伸而非大屈膝蹬脚，头腰无代偿疼痛；脚踝放松。

取舍坐池边只练双脚同步与水感，不代替完整蝶腿。

蝶泳手

双手同抓同推，同出同回；推水接移臂。

检查与适用提示

检查双臂同步且回臂舒适；水下抓推不全变成直臂下压；短段不会靠仰头甩腰撑回臂。

取舍固定双手不能完整划臂；水下回臂只暂时取消空中移臂要求。

蝶泳手与呼吸

随划起胸，低位吸气；移臂中脸先于双手回水。

检查与适用提示

检查短段内可得到气，脸先于手回水而没有猛点头；选择每划或隔划都以舒服、动作不被破坏为准。

取舍优先练好低位取气和及时回脸，不硬性要求隔划呼吸。

蝶泳完整配合

一划两踢：入水附近第一踢，推末附近第二踢。

检查与适用提示

检查同一短段前后两个周期都能见两踢分处前后；呼吸不阻断回臂，没有越游越深或动作失控；先保质量再加周期。

取舍不在面对池壁时放手游完整周期再抓回；到净空路线练。

教练怎么用

一堂课只处理一个主要现象。顺序是：用测试定阶段，打开四泳姿对应模块按口诀上课，选一个专项，立刻用完整蝶泳看原现象有没有减少。分解练得很像、一配合就改成交替腿或单臂，这一课不算通过。

诊断阶段四泳姿模块上课口令
Y0 前提不在蝶泳课重教先完成入水共同课，并能用爬泳或蛙泳安全前进
Y1 身体波动蝶泳身体波动身体向前，波由躯干传到双脚；幅度够用，头颈不甩。
Y2 蝶泳腿蝶泳腿髋带腿回摆，脚背接着鞭水；双腿同步，波小而不断。
Y3 蝶泳手蝶泳手双手同入、同抱、同推、同回；向后划水，向前放松移臂。
Y4 手与呼吸蝶泳手与呼吸随划起胸，低位吸气；移臂时脸先回水，双手随后入水。
Y5 完整配合蝶泳完整配合手入一踢，推末二踢；移臂不停，脸先于手回水，接下一轮。
Y6–Y7 保持与效率完整配合之后不再加新口诀。距离一长动作就散，就缩短，不加大波浪。

四泳姿的上课顺序是波动、腿、手、手与呼吸、配合。诊断时也不要跳步：腿还在交替或膝盖打水，不要上完整配合；手还不能同时入水，不要用抬头换气来带动身体。

波浪够用即可。不以波浪越大越合格。腰出现疼痛，立刻停止，退回小幅波动，不靠多打几趟硬撑。

阶段是否真正掌握

一个阶段不能因为偶然完成一次或游够某个距离就算掌握。需要同时满足：

  • 可重复：同一动作能够连续完成至少 3 次或 3 组。
  • 可控制：能够以较慢、较放松的状态完成，不依赖憋气、冲刺、拼命打腿或把身体甩出水面。
  • 没有明显新代偿：为了完成呼吸又出现甩头、交替腿、单臂长期代替双手，不算掌握。
  • 能带回完整蝶泳：分解练习很好，完整蝶泳一开始就全部消失，不算通过。

因此：憋气打完一段蝶泳腿，或用单臂游完 25 米，都不等于掌握蝶泳。

蝶泳学习主线

阶段核心任务建议里程碑最常见卡点
Y0 安全前提已会呼气、漂浮、回站，并能用另一种泳姿离开深水脸入水能呼气；能独立回站；爬泳或蛙泳能安全前进一段把蝶泳当成第一种入水课
Y1 身体波动波由躯干经髋腿传到脚，身体向前扶壁或短距离滑行中，胸髋顺次动，头不甩，腰不单独大折甩头、塌腰、向深处扎、用脖子带动
Y2 蝶泳腿双腿同时，髋带腿，脚背鞭水约 10～15 米双腿同步前进；膝不过度顶出；不改成交替打腿左右交替、骑自行车、收成蛙泳蹬腿
Y3 蝶泳手双手同时入水、抱水、推水和移臂不换气短距离双手同进同出；推完再回，不划到腰停住一先一后、拍水、划过腰、移臂停在前方
Y4 手与呼吸随划起胸，低位吸气，脸先于双手回水连续数次低位吸气；吸完脸回到水里；打腿不因吸气停止仰头找气、吸气时腿停、头甩向一侧
Y5 完整配合一划两踢，移臂不停连续 15～25 米；入水附近一踢，推末附近二踢两踢叠在一起、第二次踢消失、配成爬泳
Y6 连续与保持疲劳后仍是蝶泳，而不是改动作4×25 米或连续约 50 米，后程仍双手同时、双腿同时后程改单臂、改交替腿、头越抬越高
Y7 效率用够用的波浪维持速度同样用力下划次和用时较稳定；波浪不再越做越大越用力越慢、只靠加大幅度

阶段按最弱环节定。能游 25 米但仍是交替腿，回到 Y2。手和腿分开都对、一配合就散，问题在 Y5，不是再加腿力。

完整动作里要找的最早偏差

一次完整蝶泳可以看成：

双手在肩前附近入水，同时第一次打腿 → 抱水、推水，胸随划抬起并低位吸气 → 推水末段第二次打腿 → 移臂时脸先回水，双手随后入水 → 下一次。

需要分开看的是：

  • 波动从躯干往脚传，不是头先甩，也不是腰单独折一个大角。
  • 两次打腿都是双腿同时。第一次靠近手入水，第二次靠近推水结束。
  • 吸气发生在划水把胸口送起来的时候，嘴低位就够。移臂过程中脸先回到水里。
  • 移臂是放松向前，不是在身体前方停住等下一次踢腿。

看到的第一个不该出现的动作，就是这一课要处理的点。后面的混乱经常只是它的结果。

最快的定位流程

顺序测试结果说明
1能否呼气、漂浮、回站，并用另一种泳姿前进做不到：先离开蝶泳课，回入水共同课
2扶壁或陆上小幅胸髋联动只有头在甩，或腰猛折：留在身体波动，不教腿的鞭水
310 米只打蝶泳腿，手臂前伸、脸入水双腿不同时，或膝盖像骑车：留在蝶泳腿
4短距离只划手，不要求换气双手一先一后、拍水或划到腰：留在蝶泳手
5每划一次、低位吸一次头抬得很高、吸气时腿停：留在手与呼吸
6完整蝶泳 15～25 米分解都能做，配合时第二次踢消失或改成交替腿：留在完整配合
7重复 25 米或连续约 50 米前半正确、后半改动作：进入保持，缩短距离，不加新技巧

身体波动

正确表现是身体以向前为主。胸口的倾角先有一点变化，腹髋跟着，腿和脚最后响应，然后回到伸长。头顺着躯干，不主动甩。

扶壁时轻扶池壁，身体伸长，只做小幅联动。肩活动不够或头会撞壁，这一步跳过，改到能伸展的水中位置，不把池边悬胸当成默认练法。

优先练习：陆上扶稳小幅波动、扶壁低幅联动。

蝶泳腿

正确表现是双腿同时上摆、同时下打。髋先带大腿，膝自然跟随，脚背把水鞭出去。波要小，并且不断。

腿沉或前进很慢时，先看是不是头抬着、腰折着、脚在勾，不要先加脚蹼。脚蹼只在双腿已经同时、需要多一点推进来体会脚背时短时使用，用完必须脱掉复测。

优先练习：扶壁同时打腿、前伸打腿、一次打腿后滑行。

蝶泳手

正确表现是双手同时入水、同时抱水、同时向后推、同时向前移臂。推水接移臂，不在腰旁或头前停一拍。移臂放松向前，水下是在向后划。

左右手一前一后，先不要用「完整节奏」去盖住它。先让双手一起完成短距离不换气划水。

优先练习：陆上双手画臂、短距离不换气划臂、推完立即移臂。

手与呼吸

正确表现是随划起胸，嘴在较低的位置吸气，移臂时脸先回水，双手随后入水。水下仍要呼气，不要憋到抬头那一下才吐。

初学按每划一次吸一次。头不再甩、腿不再停之后，再练隔次吸气。隔次吸气不是更高级的呼吸义务，只是少抬一次头。

优先练习：每划一吸的短距离、吸完脸先回水。

完整配合

口令是：手入水附近第一踢，推水末附近第二踢；移臂不停；脸先于手回水。

两次踢叠在同一次推水里，或第二次踢被吸气吃掉，都还不是完整配合。单臂蝶泳可以用来看某一侧是否领先，但练完要马上回到双手，不能把单臂当成蝶泳的成品。

优先练习：口令慢游、单臂各数次后立即双手、前半专项后半完整。

连续、保持和效率

前 15 米是蝶泳、后面改成爬泳腿或单臂，说明距离已经超过现在能保持的技术，不是「再用力一点就过了」。把长距离拆成多组短距离，动作一散就结束这一趟。

效率阶段看的是同样放松的用力下，划次和用时稳不稳定。波浪继续加大、速度反而下降，退回小幅，不把大幅度当成进阶。

常见现象

波动和身体位置

看见的现象先查什么主要影响专项
头上下甩，身体却几乎不向前波从脖子开始，胸髋没有先动头部代偿，腿得不到连续的波陆上和扶壁：头颈顺着躯干，只做小幅胸髋
腰单独折一个大角，或练完腰痛用塌腰或顶髋制造波浪力停在腰，脚没有鞭水；有受伤风险立刻减小幅度。侧面看胸、髋、腿是否顺次，而不是腰先折
身体向深处扎，前进很少头和手向下钻，波的方向错了每一下都在下潜，第二次踢更难做口令「身体向前」。手入水后向前伸，不向池底压
整个身体很僵，波传递不出去为了外形屏气、耸肩腿只能用膝盖打先呼气，缩短距离，恢复伸长再打下一波

蝶泳腿

看见的现象先查什么主要影响专项
两条腿左右交替还在用爬泳腿前进这不是蝶泳腿，配合后会更散扶壁看双腿是否同时。不同时就不加手
膝盖一下一下顶出水面主动抬膝，髋没有先带大腿迎水，前进变慢小幅打腿。口令「髋先带，膝只跟随」
收成蛙泳那样蹬夹用已经会的蛙泳腿代替节奏变成一收一蹬，接不上下一次划臂腿保持向后延伸，只做上下，不做外翻蹬夹
打得很响、水花很大，人几乎不走脚掌拍水，脚踝僵消耗大，推进小放慢，脚背接水。有小水花可以，拍水不算通过
一划手，腿就停注意力全到手上，腿还不能自己继续移臂时身体下沉先在两次划水之间连续打腿，再把划水加回来

划臂、呼吸和配合

看见的现象先查什么主要影响专项
一只手先入水左右不同时，或一侧肩更习惯发力身体左右扭，第二次踢会偏短距离双手一起入水。单臂只用来找出弱的一侧，然后立刻双手
手掌拍到水面上移臂结束时手掌向下砸节奏被打断，水花打到脸手向前送进水里，不从高处拍下
手划到腰旁还在拉，或在腰旁停住推水过长，错过移臂时机第二次踢对不上，身体停一下推完就向前移臂，不在腰旁等
双手在头前停很久才划在等踢腿或在等吸气前进中断，腿被迫停移臂不停。踢腿跟着入水和推水，不让手停下来等
吸气时头抬得很高用仰头找气，胸口没有随划起来髋部下沉，第二次踢消失低位吸气。嘴刚能吸到就可以，脸随移臂先回水
只有一次踢，或两次踢叠在一起时机还没分开一划两踢没有形成慢速口令：手入一踢，推末二踢。做不到就退回只打腿
前半程是蝶泳，后半程改单臂或交替腿距离超过能保持的技术错误动作被反复练熟缩短。一改动作就停，休息后再来

专项练习

每个练习都短。出现腰痛、交替腿或头猛甩，就停止这一趟。

  • 陆上小幅波动

    做法站稳扶住，胸的倾角先变一点，腹髋跟着，腿最后响应，头不甩

    主要解决只会甩头或塌腰

  • 扶壁低幅联动

    做法轻扶池壁，身体伸长，胸髋小幅接着动。头会撞壁或肩不够就跳过

    主要解决水里仍用腰折一个大角

  • 扶壁同时打腿

    做法双手扶壁，只看双腿是否同时上下，膝不主动顶出

    主要解决交替腿、骑车腿

  • 前伸打腿

    做法双手前伸、脸入水，连续小幅蝶泳腿约 10 米

    主要解决打腿不能在没有扶壁时保持

  • 一次打腿后滑行

    做法流线里只打一次，然后滑行，感受脚背是否把身体送向前

    主要解决一直拍水却不前进

  • 陆上双手画臂

    做法双手同时从前方向下向后，再放松回前方。不划到身后很远

    主要解决左右不同时、不知道移臂何时开始

  • 短距离不换气划臂

    做法脸入水，双手完成数次同入同推同回，腿保持小幅同时打

    主要解决一换气手就乱

  • 推完即移臂

    做法手推到髋旁附近就向前送，不在腰旁停

    主要解决划水过长、停顿

  • 每划一吸

    做法随划起胸，低位吸一次，移臂时脸先回水。每次只游很短

    主要解决仰头、吸气时腿停

  • 口令慢配合

    做法大声或心里数：入水一踢，推末二踢。移臂不停

    主要解决两次踢分不开

  • 单臂找弱侧

    做法一只手前伸，另一只手划，左右分开做数次，然后马上双手一起

    主要解决一只手领先。单臂本身不是蝶泳成品

  • 前半专项、后半完整

    做法同一趟前半只打腿或只按口令，后半完整蝶泳

    主要解决专项和完整泳脱节

  • 短组质量游

    做法多组 15～25 米，动作一改成就停

    主要解决后程改成别的泳姿

  • 划次对照

    做法同样放松的用力，数每趟双手入水的次数和用时

    主要解决越用力波越大、人越慢

短脚蹼只在双腿已经同时、需要一点推进来感觉脚背时使用。脱掉之后必须再打一段不穿脚蹼的腿，并看完整蝶泳有没有把交替腿带回来。

一堂课怎么排

1. 先看今天的一个现象，定在 Y1 到 Y5 的哪一层。

2. 用四泳姿该模块的口诀做陆上或扶壁，再下水。

3. 从上面的列表里选一个练习，做数组短距离。

4. 立刻游完整蝶泳，只保留这一句口令。

5. 不提示再游一次。原现象还在，就留在这一层，不进入下一个模块。

不要在一堂课里从波动一直练到完整配合。

容易误导的说法

不够准确的说法上课时改成
波浪越大越好幅度够用，身体向前，头颈不甩。
腰要用力折胸先动，髋跟着，腰不单独折成一个大角。
蝶泳腿就是爬泳腿打快一点双腿同时。左右交替就还不是蝶泳腿。
膝盖打直不能弯髋先带，膝自然跟随，不能主动把膝盖顶出水面。
手要划到最后向后推完就向前移臂，不在腰旁停留。
抬头越高越喘得上气随划起胸，低位吸气，脸先回水。
先把 25 米游完再管动作一改成交替腿、单臂或猛甩头就停。
单臂蝶泳就是蝶泳单臂只用来找左右差异，成品是双手同时。

不放进初学主线的内容

出发、转身、出发后的水下蝶泳腿，以及为了潜远而连续水下打腿，都等表面蝶泳已经稳定之后再单独学。水下闭气需要有人在场，不作为本册的练习目标。

开放水域里的意外和离水，用自救册，不用蝶泳的配合口令去处理。

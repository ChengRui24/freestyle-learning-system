1. 成人零基础：USMS Adult Learn-to-Swim（ALTS）路径

1.1 先判断是哪类成人学员

[USMS] ALTS Volunteer Teacher Swim Lesson Guide 把常见成人学员至少分为四类：

  • 不怕水的不会游者；
  • 已会游、需要改善泳姿者；
  • 会游但呼吸困难者；
  • 怕水的不会游者。

教学开始前先了解既往水中经历和目标。成人即使已有狗刨等基础，教材仍建议从基础能力开始检查，以确认基础技能确实掌握；一项能力表现出来后立即进入下一项，进度跟随学员，而不是要求所有人按同样课时推进。

官方教材：https://www.usms.org/alts/alts_aprilvolunteerguide.pdf

1.2 General Teaching Progression：官方基础顺序

阶段USMS 技能核心教学内容通过信号/注意点
1Bobs 沉浮呼吸站立扶墙，下潜时向水中呼气，出水只完成吸气；教材建议课初至少做约 10 次重点观察水下是否真正呼气、出水是否还在吐气；吸气走嘴
2Front Float 俯卧漂浮深吸气后面部入水，利用肺中空气感知浮力；必要时轻打腿初学尝试时控制时间，避免因紧张在面部仍入水时吸气；抬头会使腿下沉
3Standing Up 漂浮恢复站立双手向下压/扫水，同时抬头、双膝收向胸部，从水平恢复垂直两膝应同时收回，不要一条腿拖在身后
4Back Float 仰漂学会仰卧让水支撑身体；能自然呼吸、观察环境、必要时呼救头部后放、腹部向上；抬头常导致髋部下沉
5Front Glide 俯卧蹬壁滑行一手扶墙、双脚蹬墙，吸气后面入水，两手叠放，肘伸直、上臂夹耳目标是建立流线型和无额外动作的前进感
6Back Glide 仰卧蹬壁滑行仰卧、耳朵入水，温和蹬壁，保持身体伸展避免因为紧张抬头使身体折叠
7Flutter Kick 自由泳腿快、均匀、小幅；膝盖“直但放松”，脚踝放松；立即加入滑行前踢时脚不要过度出水；仰踢时膝盖不要明显顶出水面
8Freestyle without breathing 不换气自由泳先把蹬壁、打腿和基本手臂动作连起来，不同时增加侧向换气复杂度一次只纠正 1–2 个重点，避免信息过载
9Freestyle with breathing 加入自由泳换气回到 Bobs → 扶墙单臂与转头 → 一次换气 → 增加换气次数和距离观察水中呼气、换气时是否抬头、出水时是否真正在吸气

1.3 呼吸困难成人的检查方法

[USMS] 对“会游一池但很快喘”的成人，ALTS 教材建议先看其完整游一池，然后只检查呼吸相关信号：水中是否持续出现气泡；换气时是否把头抬出水面；转头后是否还能听到呼气声。如果是，应先让学员把注意力从手腿动作移开，集中在“把气排到水里、转头时用嘴吸气”。

1.4 ALTS 与竞技呼吸训练不能混淆

初学者首先解决的是安全的空气交换与水中舒适度；进阶泳者才可能做 restricted breathing 等专项。USMS 2023 的 breath-control 安全文章明确指出：水下憋气存在 shallow-water blackout 风险，呼吸控制训练绝不能无人监督，也不应变成极限憋气或过度换气训练。见第 18 节安全规则。

2. 从“会游”到“会训练”：Swimming 101

[USMS] Swimming 101 推荐的四部分顺序是：The Basics → The Stroke Basics → Adult Swim Training → Events 101；可以按需求跳转，不是强制线性课程。

真正进入 Masters 训练前，至少应会理解：

  • warm-up、drill、kick、pull、main set、cool-down；
  • choice、free、stroke、IM；
  • open turn、flip turn、streamline、underwater。

3. USMS 技术 Guide 的标准使用方式

[USMS] 当前四泳姿和 transition Guides 的典型模块结构是：

  • 约 6 篇 big-picture 技术文章：解释机制、常见错误、速度/耐力影响；
  • 10 个 progressive drills：从较简单到更复杂；
  • 通常 5 个 sets：把 drill 与完整泳姿、速度、划数、距离结合；Turns 的 dedicated set 页面当前为每类 4 组；
  • 10 个 dryland exercises：补充活动度、稳定、力量或爆发能力。

4. Drill、Set、Workout：三层不能混为一谈

4.1 Drill

[USMS] Drill 是专门改善技术组成部分的练习。USMS 的 workout-writing 指南强调：每个 set 都要有目的；drill 的重点是正确执行，不是为了游快。如果 drill 做错，会强化错误习惯，因此需要及时反馈。

4.2 Set

Set 把“动作 + 距离 + 次数 + 强度/目标 + rest/send-off + 器材”组合成一个训练刺激。例如同一个 Closed Fist：做 4×25 慢速技术感知和做 8×50 fist/open 交替并要求相同划数，是完全不同的训练任务。

4.3 Workout

USMS workout-writing 指南给出的典型 Masters 结构：

1. Warm-up；2. Drill/technique focus；3. Main set；4. Pull or kick set；5. Supplementary set；6. Cool-down。

Warm-up 与 cool-down 被该指南视为必要组成；其余模块根据目标增删和排序。Main set 通常占整堂训练约 1/3–2/3，但不是硬性规则。

官方说明：https://www.usms.org/fitness-and-training/articles-and-videos/articles/how-to-write-a-swimming-workout

5.2 Rest 与 Send-off

  • @:20 rest：每次完成后固定休息 20 秒；不同速度泳者的出发时刻不同。
  • @1:30：每 1分30秒统一开始下一次；游得越快，本次获得的休息越多。
  • USMS workout-writing 指南明确指出：工作/休息比决定训练性质。最大速度需要长恢复；距离配速训练通常用更短恢复。相同的 10×50 @2:00 对 30 秒完成 50 的泳者可能是 sprint set，对需要 1:30 才完成的初学者则不是同样的生理刺激。

5.3 不把 USMS 虚构成统一“Zone 1–5”

[结构化整理] 当前 USMS Workout Library 与 Guides 实际同时使用 easy/cruise/steady/solid/strong/fast、pace、race pace、CSS、fixed rest、send-off、best average、sprint、test set 等表达。本文因此不声称存在一个 USMS 官方统一五区心率表。需要强度处方时，应优先保留 USMS 页面给出的 目标速度 + 重复距离 + 休息/间歇 + 技术要求。

6. 器材：不是“越多越好”，而是改变任务约束

器材/限制USMS 中的典型用途使用原则
Fins 脚蹼增加推进、帮助身体位置、让一臂蝶等高技术动作更容易维持节奏，也可做高速/腿部训练既可“辅助”也可“加负荷”；撤掉脚蹼后要回到完整泳姿验证迁移

8. 四种泳姿的关键技术原则与学习路径

这一节只写 USMS 当前 Guide 明确强调的核心机制；“路径”部分是把这些技术模块按前置关系做的 [结构化整理]，不是 USMS 强制课表。

8.1 自由泳

技术重点 [USMS]

  • 身体位置：当前 Freestyle Body Position Guide 把身体位置视为自由泳速度/效率的基础。肺部浮力提供支撑；通过头胸位置、髋腿控制和转体减少阻力。
  • 呼吸：目标是低、直、快的呼吸；换气时尽量保持头与脊柱对齐，靠旋转而不是抬头/侧拉头部。水下完成大部分呼气，嘴出水时快速吸气。
  • 划水：当前 Guide 强调手+前臂共同形成有效受力面，建立抓水后向后推水；手臂恢复应服务于下一次有效入水/抓水。
  • 打腿：自由泳腿是小幅、高频、相对直腿的交替踢；USMS Guide 强调它同时承担身体位置、转体协调和推进。
  • 换气频率不是一个固定数字：Guide 根据比赛持续时间、个人划频和舒适度讨论不同模式，并明确单侧或双侧都可能有效；训练中偶尔练弱侧有助于对称。

学习/纠错路径 [结构化整理]

水适应与稳定呼吸 → 肺部浮力/身体线 → 无呼吸干扰的划水/打腿 → 低而快侧向呼吸 → 转体与双臂时序 → drill/swim 迁移 → 划数+DPS+速度 → 疲劳/高速下保持技术。

官方 Set 使用例：Body Position Set 1

  • 6 轮；每次之间休 10–15 秒。
  • 第 1/4 轮 cruise；第 2/5 轮所有游泳数划；第 3/6 轮 build。
  • 每轮：10 秒 Ball Float + 25 free → 10 秒 Passive Jellyfish + 25 → 10 秒 Active Jellyfish + 25 → 10 秒 X-float + 25 → 50 free。
  • 设计思想：每次完整自由泳前重新唤起身体位置感觉；随后分别用巡航、划数和加速增加迁移难度。

官方 Set 使用例：Kick Set 2（速度变化）

  • 2 轮，重复间休 15–20 秒。
  • 3×（Wall Kick：10 秒 solid + 10 秒 strong + 10 秒 fast + 20 秒休）；3×50 free 按腿部力度 descend；3×50 snorkel kick descend；再 3×50 free descend。
  • 再以 Vertical Kick 复现同样 solid→strong→fast，随后自由泳；最后仰卧流线打腿 3×50 descend + 自由泳整合。
  • 核心不是“某一趟绝对多快”，而是学会可预测地用腿改变速度。

8.2 仰泳

技术重点 [USMS]

  • 身体水平：尽量让头、髋、脚接近水面。Guide 用“肺部是跷跷板支点”解释为什么降低头/肩可帮助髋腿上浮，但同时提醒不要用腰椎过度反弓来“压头”。
  • 转体：USMS 当前 Body Position Guide 特别纠正“仰泳应持续匀速左右滚动”的误解：拉水阶段可以保持一侧转体，拉水结束后再快速转向另一侧。
  • 划水：尽早让手和前臂朝后，建立弯肘受力面，再向后推水；恢复臂相对直，转体帮助肩部完成大范围动作。
  • 打腿：小幅、持续 flutter kick；腿不仅推进，也维持身体位置和节奏。

学习路径 [结构化整理]

仰漂舒适 → 头/髋/腿排列 → 基本 flutter kick → 侧身平衡 → 单臂抓水 → 双臂交替 → 延迟转体 → 划数/速度 → 长距离/高速保持。

8.3 蛙泳

技术重点 [USMS]

  • 蛙泳速度高度依赖 推进与阻力的交替管理，不是手腿“同时向后发力”。Current Timing Guide 的大量 drill 正是在训练手腿分离、流线和时序。
  • 腿部回收：Kick Guide 的仰卧动作重点是脚跟向臀部回收，同时控制膝盖向前移动；脚部外翻和快速完成推进很关键。
  • 手臂：前臂+手共同受力；拉水之后要积极把手臂送回流线。
  • 身体位置：呼吸抬头过高会让髋下沉；Snorkel、Every-Other-Stroke Breathing、Head-Up 等 drill 用“去掉或夸大呼吸”来建立反差。
  • Timing 会随距离/速度改变：Stroke-Count Gears 与 Speed Gears 明确训练不同划幅和速度下的配合，而不是把一种节奏当作所有距离的唯一答案。

学习路径 [结构化整理]

流线与身体位置 → 蛙泳腿 → 手臂抓水/前伸 → 手腿分离（3/2 pull-kick drills）→ 正常一划一蹬 → 呼吸与髋部位置 → 划数/时序档位 → 速度和比赛节奏。

官方 Timing Set 1 例

  • 1–2 轮；单次约休 20 秒，轮间约 40 秒。
  • 8×25：奇数 Underwater Breaststroke，偶数 Delay Breaststroke。
  • 4×25 正常蛙泳：每 25 比平常少 1 次动作。
  • 8×25：奇数 Two Pulls, One Kick；偶数 Two Kicks, One Pull。
  • 4×25 正常蛙泳：每 25 比平常多 1 次动作。
  • 用途：在“分离动作”和“完整动作”之间来回切换，并主动探索划数改变后的时序。

8.4 蝶泳

技术重点 [USMS]

  • 两次腿的时点：Current Timing Guide 明确强调每次完整划臂两次腿——一次在手入水后帮助重新建立身体排列，一次在划手完成/手出水附近完成，帮助髋部上升、手臂恢复和推进。
  • 不是波动越大越好：Body Position Guide 用 flutter-kick butterfly、前伸/贴体单臂蝶等动作控制波幅。
  • 划水：先建立手和前臂朝后的受力位置，再加速向后推；划水产生的手速帮助双臂水上恢复。
  • 动作质量优先：USMS 蝶泳相关文章反复建议，疲劳到动作严重破坏时继续堆低质量完整蝶的价值有限；短距离、高质量重复和 drill 过渡更适合很多 Masters 成人。

学习路径 [结构化整理]

浮力/身体位置 → 海豚腿双向推进 → 单臂蝶控制波幅 → Skate 建立划水与两次腿 → 呼吸位置 → 脚蹼/呼吸管辅助完整蝶 → 撤辅助 → 划数/速度档位 → 短距离高质量反复 → 更长距离耐力。

官方 Timing Set 1 例

  • 4 轮；奇数轮戴脚蹼，偶数轮不戴；每次休 20 秒，轮间 40 秒。
  • 2×25 单臂蝶（非划手臂前伸，左右各一次）→ 25 Skate → 2×25 单臂蝶（非划手臂贴体）→ 25 Skate → 25 butterfly strong → 25 scull easy。
  • 设计思想：从低复杂度单臂 timing → 双臂 Skate → 完整蝶强度输出，再用 scull 恢复。

9. 池壁与 Transition：出发、转身、水下不是“附属动作”

USMS 当前把 Starts、Turns、Underwater Kick 单独做成 Guides，说明池壁技术是训练能力，而不是泳姿学完后顺便一提。

9.1 出发的共同结构 [USMS]

正面、仰泳、接力出发虽然姿势不同，但都可拆成：起始姿势 → 发力/离台或离墙 → 空中阶段 → 入水 → 从入水到正常游的 transition。

正面出发核心：不要只追“尽快离台”，还要把身体有效投射到水面上方，并通过干净入水和流线保留速度。

仰泳出发核心：从水中强蹬墙，向上/向后投射并形成后向入水，再迅速进入流线。

接力出发核心：跨步/摆臂带来更高初速度，但必须与来泳者触壁时间同步；高速度也使干净入水更难，因此 progression 先把动作和入水质量建立起来。

9.2 翻滚转身 [USMS]

完整质量链：保持进墙速度 → 最后完整划水 → 紧凑滚翻/双膝向胸 → 脚落墙 → 强蹬 → 先建立流线再离墙 → 平顺 breakout。常见错误包括提前减速、翻滚松散、蹬墙弱、流线差、突然抬头出水。

9.3 开放式转身 [USMS]

核心仍是速度、紧凑收膝、强蹬和流线。蝶/蛙比赛触壁有规则要求；自由泳也可使用单手开放式转身作为 flip turn 的替代。

9.4 IM transitions [USMS]

  • Butterfly → Backstroke：以蝶泳规则触壁并完成类似开放式转身的紧凑收膝，但蹬墙后直接在背面进入仰泳。
  • Backstroke → Breaststroke：需在背面触壁并在正面蹬出；Guide 介绍侧转开放式、后滚式、crossover 等不同技术。
  • Breaststroke → Freestyle：与蛙泳开放式转身最接近，但蹬墙深度和随后水下策略可不同。
  • Current IM page 明确让泳者把 open-turn drills、sets、dryland 调整后用于 IM，而不是另造一套完全独立动作。

IM Guide：https://www.usms.org/fitness-and-training/guides/turns/im-turns

9.5 水下海豚腿 [USMS]

USMS Current Underwater Kick Guide 把它拆成两条能力：

  1. Body Alignment：上身稳定、脊柱排列、流线、控制躯干波幅、寻找个人最合适的腿部幅度；
  2. Propulsion：脚在有效范围内快速移动、双向推进、加速踢水，并用 vertical/resisted/single-leg 等动作放大推进反馈。

Guide 反复强调“推进与阻力的权衡”：腿幅太小推进不足，太大又增加阻力；需要通过 Big-to-Small / Small-to-Big 等 drill 找到个人平衡。

10. Drill 怎么真正“用起来”：技术迁移方法

10.1 USMS 常见的 Drill → Swim 结构

Current Guide 的 sets 很少让泳者连续长时间只做一个 drill，而是经常采用：

短 drill → 完整泳姿 → 再 drill → 更快/更长完整泳姿 → 划数或配速约束。

这样做的意义是检验：专项中出现的动作感觉能否迁移回真正游泳。

10.2 一项 drill 至少有四种用法 [结构化整理自 USMS set 设计]

1. 感知型：低速短距离，只找某个感觉，如 Wall Pull、Ball Float。

2. 隔离型：暂时移除一个复杂因素，如 snorkel 去呼吸、pull buoy 去腿部推进。

3. 约束型：用拳、倒置划手板、网球、阻力等限制某个补偿动作。

4. 迁移型：drill 后立即完整泳姿，并加入 stroke count、build、descend、race pace 或距离。

10.3 什么时候不能继续加距离

USMS workout-writing 指南的原则是：drill 错误会强化错误动作。速度/耐力文章同样反复强调，如果技术开始明显崩坏，需要改变强度、距离、休息或动作形式，而不是只追训练量。

12. 单次 Workout 的设计与调整

12.1 先问目标，再写训练

USMS 2023 workout-writing 指南要求先明确：目标是什么、为谁写、出勤是否稳定、术语如何解释、训练如何传达。每一个 set 都应能说清楚目的，例如降低阻力、提高 power、aerobic fitness、水感、心理韧性或恢复。

12.2 Main Set 的核心变量

  • Duration；
  • Repeat distance；
  • Stroke；
  • Rest 或 send-off；
  • Number of repeats；
  • Recovery swim；
  • 必要时器材、划数、呼吸模式、turn/underwater 要求。

12.3 同一 set 如何适配不同速度

USMS 指南给出三种典型调整：

  1. 慢泳者减少 repetitions；
  2. 保持 repetitions，但缩短每次距离；
  3. 把 set 写成固定总时长，每个人在这段时间内完成自己能完成的 swim/rest 循环。

12.4 器材不能当“作弊工具”

USMS workout-writing 指南明确指出 fins、buoy、snorkel 等可以增加力、提高速度或改变 drag profile，但应有明确训练目的，而不是仅为了让训练变轻松。

14. 测试、Benchmark 与数据反馈

14.1 Test Set

[USMS] Test Set 的关键不是“某个神奇测试”，而是 同一条件重复。可以是一条全力100，也可以是重复组。要记录日期、泳池长度、动作、器材、rest/send-off 和结果，未来才能比较。

14.2 技术效率指标

  • Time / Split / Pace：速度的直接结果；
  • Stroke Count：动作次数；必须与时间一起看，低划数但明显变慢不等于更高效率；
  • DPS：每划距离；
  • Stroke Rate：划频；不同速度/距离最佳值可能不同；
  • SWOLF：时间+划数形成的粗略效率指标，适合同一个人、同样环境下趋势比较，不应脱离速度和泳姿解释。

15. Open Water：不是“泳池自由泳游得更长”

15.1 USMS Open Water 101 的范围

Current Open Water 101 覆盖：安全、泳池与开放水域差异、装备、防寒泳衣、地点、常见风险、海洋生物、焦虑/恐慌、赛事选择和训练。

官方入口：https://www.usms.org/fitness-and-training/guides/open-water-swimming-101

15.2 技能路径 [结构化整理自官方 Guide]

泳池高效自由泳 → 长距离稳定技术 → 双侧/环境适应换气 → sighting → 直线游 → buoy turn → drafting → pack/身体接触 → 不同水况和划频 → pacing → feeding → 开放水域比赛策略与安全判断。

15.3 Sighting

USMS Guide 举例的常见方式是 alligator eyes：头只抬到泳镜刚露出水面观察，随后迅速回到正常身体位置；Guide 给出的示例频率是约每 5–10 划观察一次，但真实频率要随能见度、航向和比赛环境调整。

15.4 Buoy Turn

池内可以把浮板放在泳池中部模拟浮标，练绕过后改变方向；Guide 也介绍翻到仰面、用几次仰泳划水帮助绕标的策略。

15.5 Drafting

开放水域要学会在其他泳者后方/侧后方利用尾流。USMS 把 drafting 视为重要开放水域技能；实际训练应在有同伴、规则明确的条件下进行，避免不断拍打前方泳者脚部。

15.6 泳池里怎么练开放水域

  • sighting；
  • straight-line swimming；
  • drafting / closely spaced swimming；
  • dead-stop starts/turns，减少对池壁反弹的依赖；
  • 浮板模拟 buoy；
  • 改变 stroke rate；
  • bilateral/environment-adaptive breathing；
  • 长距离 pace；
  • 在长距离赛事准备中练补给产品和踩水进食/喝水流程。

16. Triathlon、回归训练、低容量：不同目标需要不同路径

16.1 Triathlon

2026 USMS triathlon 专题把 Masters Swimming 的价值归纳为：现场技术反馈、结构化 interval、pacing、stroke variety、sprint、threshold、recovery swimming，以及 drafting/sighting 等开放水域技能。核心目标通常不是把泳池 50 米做到极致，而是在开放水域以较低能耗完成游泳段，并为自行车/跑步保留能力。

来源：https://www.usms.org/fitness-and-training/articles-and-videos/articles/how-triathletes-should-use-masters-swimming-to-improve-swim-times

16.2 Return-to-Swimming

USMS 的“伤后/中断后重新游泳”文章强调回归是过程：伤病后先与医生沟通运动目标和许可；年龄增加后恢复通常更慢。[结构化整理] 对曾经竞技但长期停训的人，不应因为“技术记忆还在”就直接恢复过去训练量，宜先恢复水感/技术质量和低容量，再逐步加 volume 和 speed。

来源：https://www.usms.org/fitness-and-training/articles-and-videos/articles/how-to-start-swimming-again-after-an-injury-or-hiatus

16.3 Low-Volume / Limited Mobility

Workout Library 专门保留约 2K 的 Low-Volume or Limited Mobility Training。这意味着“技术高级”与“训练量大”不是同一个维度；成人可以技术很成熟，但因为时间、年龄、恢复或活动能力选择低容量训练。

17. Dryland：从辅助项升级为正式能力系统

Current stroke/transition Guides 给每个技术模块配置 dryland exercises，说明 USMS 并不把所有技术问题都只放在水里解决。

17.1 USMS 强度/动作分类思想

USMS 经典 Strength Training: A Balanced Approach 建议按 movement pattern 而不是“胸日/腿日”思考：

  • Push；
  • Pull；
  • Knee-dominant（如 squat/lunge）；
  • Hip-dominant（如 deadlift/hinge）。

文章特别建议游泳者不要出现“推远多于拉”的力量计划，并强调下肢也要平衡 knee- 与 hip-dominant。

来源：https://www.usms.org/fitness-and-training/articles-and-videos/articles/strength-training-a-balanced-approach

17.2 核心不是只有卷腹

USMS core 系列把核心视为三维的稳定/传力系统，包含仰卧、俯卧、垂直等方向训练。对游泳而言，目标是让四肢发力时躯干保持稳定并有效传递力量。

17.3 Dryland 测试

USMS “Three Dryland Tests for Improved Swimming” 建议用简单测试找弱项，并大约每季度复测。文章包括肩部活动范围等项目，并建议用手机录像自评。

来源：https://www.usms.org/fitness-and-training/articles-and-videos/articles/three-dryland-tests-for-improved-swimming

17.4 Guide 内 dryland 的基本剂量

多个 Current Guide dryland 页面给出的通用起点是：多数动作 1–3 组 × 8–10 次（静态保持类除外）；新动作可先从 1 组开始，再逐渐增加。具体动作仍应按对应泳姿 Guide 的目的选择，而不是把所有 dryland 全堆在一次训练。

18. 安全边界与注意事项

18.1 Breath control / 水下训练

[USMS 明确安全要求]

  • 水下憋气存在 shallow-water blackout 风险。
  • breath holding 与 breath control 不是同一回事；USMS 建议强调受控、渐进的呼气和呼吸节奏，而非追求极限憋气。
  • 绝不无人监督练习水下憋气/限制呼吸。
  • 需要空气就呼吸；不要把“几划一换气”当作必须完成的挑战。
  • 逐步增加水下距离/减少呼吸，并给充分恢复，而不是突然挑战很长距离。

来源：https://www.usms.org/fitness-and-training/articles-and-videos/articles/how-to-work-safely-on-breath-control

18.2 出发

Current Starts Drill pages 每页都明确写：出发及出发 drill 应由合格教练指导，并在泳池深水端练习。 不应在不明水深、浅水、拥挤泳道自行试跳台。

18.3 蛙泳夹浮漂蹬腿

USMS 当前 Breaststroke Kick Drill 明确警告：Kick With Pull Buoy Between Legs 可能比其他蛙腿练习给膝盖更大压力；开始要慢，把它当技术练习而非体能训练。

18.4 高阻力动作

Parachute、DragSox、Tombstone 等的目的在于放大压力和力量需求。Current Guides 多次把这类动作安排成短距离；当阻力使动作模式崩坏时，继续堆距离会偏离 drill 目的。

18.5 Open Water

USMS Open Water 101 的核心安全原则包括：

  • 不要独游，优先与熟悉当地环境的开放水域群体/伙伴游；
  • 使用醒目的泳帽和 tow float 提高可见性；
  • 入水前评估水温、风向、船只/垂钓/冲浪等交通、天气和雷暴、潮汐/水流/离岸流、野生动物、水质和本地临时风险；
  • 冷水未适应时缩短时间并靠近可快速上岸区域；
  • 如果环境发生威胁性变化，应退出水域。

来源：https://www.usms.org/fitness-and-training/guides/open-water-swimming-101

18.6 恢复与成人个体差异

USMS recovery 与 taper 资料反复强调成人年龄、伤病、训练史、工作和家庭负荷差异。恢复训练、cool-down、补水、营养和睡眠应视为训练组成；年龄增加通常需要更多恢复。

Recovery：https://www.usms.org/fitness-and-training/articles-and-videos/articles/why-you-need-to-do-more-recovery-swims

19. 诊断与反馈：Video Stroke Analysis / Stroke Clinic

19.1 Video Stroke Analysis

Current USMS Video Stroke Analysis 的标准流程非常接近一个结构化技术闭环：

  1. 选择一个泳姿，或 starts/turns；
  2. 按规定角度录像；
  3. USMS coach 给第一轮约 5 分钟分析；
  4. 聚焦 3 个主要改进点；
  5. 书面反馈给出对应 3 个 drills 和进一步资源；
  6. 泳者练习数周；
  7. 重新录像，做第二轮 follow-up。

这形成：Observation → Priority Problems → Drill Prescription → Practice → Revideo → Reassess。

官方页面：https://www.usms.org/fitness-and-training/usms-video-stroke-analysis

19.2 Stroke Development Clinic

USMS Clinic Course 明确训练教练如何设计 stroke development clinic，并使用四泳姿的 drill/swim progression。现场诊断的关键不是一次给出十条建议，而是选择有限重点、做 drill、反馈、再回到完整泳姿。

20. 教练体系与当前状态

USMS 过去的 Coach Certification 四级结构可以用来理解其知识框架：Level 1 偏成人学习者/训练写作，Level 2/Stroke School 偏四泳姿与出发转身纠错，Level 3 扩展到项目管理、特殊人群、dryland、营养和 injury prevention，Level 4 强调长期专业贡献。

结论：USMS 的真正“完整构成”

如果只看 drill，USMS 像一个动作库；把全部系统连起来后，它实际上是：

Adult Learn-to-Swim → Training Literacy → Stroke/Transition Technique → Progressive Drills → Sets → Workouts → Goal-based Plans → Intensity/Pace Methods → Dryland → Open Water/Triathlon/Special Populations → Assessment/Tracking → Coaching Feedback → Periodization/Recovery → Long-term Participation。

其中 Current Guides 的 220 条水中 drill 是“动作原子层”，并不是整个系统的终点。真正训练价值来自：选对问题 → 选对 drill → 在 set 中迁移 → 在目标强度下保持 → 用重复测试和数据反馈判断是否真的改变。

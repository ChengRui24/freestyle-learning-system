自由泳完整学习体系 3.0

日常把爬泳称为自由泳，本文统一用「自由泳」。

使用顺序

A 阶段→ C 现象→ B 根因→ D 专项→ E 闭环→ F 规则
步骤看什么
A 阶段当前真正卡在哪一层
C 现象先写看到了什么
B 根因按优先序找最早失效环节
D 专项1 个主问题 + 最多 1 个辅助
E 闭环专项后必须完整泳复测
F 规则巩固、进阶或退阶

学习主线不是打腿 → 划手 → 换气 → 拼起来。专项是否有效，只看：回到完整自由泳以后，原来的问题是否减少。

阶段是否真正掌握

不能因为偶然完成一次或游够某个距离就算掌握。四项需同时满足。

  1. 1 可重复同一动作连续至少 3 次或 3 组。
  2. 2 可控制较慢、较放松完成；不依赖憋气、冲刺、拼命打腿、大幅度代偿。
  3. 3 无明显新代偿例如为换气又出现抬头、剪刀腿、前手下压、过度翻转。
  4. 4 能带回完整泳分解很好但完整泳一开始全部消失，不算通过。

憋气冲完 25 米 ≠ 掌握 25 米自由泳。

学习主线 A0–A8

问题诊断六步

不要看到哪里动作难看，就直接改哪里；先找到最早失效的环节。

  1. B1 看具体现象写「看到了什么」，例如换气时腿突然分开。不要直接写「核心弱」。
  2. B2 最早失效环节

    某环节失效，指它已经不能按正确要求做到、不稳定，或必须靠憋气、冲刺、代偿才能完成。

    按下面这条优先序从前往后找第一个失效点

    呼吸→ 头部和身体线型→ 侧身平衡与转动→ 打腿→ 入水和水下划水→ 完整配合和疲劳
  3. B3 简化练习拆开正面呼吸管、侧身打腿、单臂、夹浮漂、脚蹼、小划手。
  4. B4 直接问题 vs 上游例如双腿分开可能只是现象，上游可能是换气抬头。
  5. B5 选一个主要专项不要一次纠正五个动作。1 个主问题 + 最多 1 个辅助。
  6. B6 完整泳复测无改善：练习选错、根因错、或尚未完成向完整泳迁移。

快速诊断测试

戴器材只为隔离变量。选型见 呼吸管、脚蹼、划手掌。

专项练习库

分类以 USMS 自由泳四域（身体位置与转动、打腿、划水、呼吸）为基础，并拆出移臂与入水、单臂与协调、效率与技术耐力、开放水域。

常用专项练习链

每一步只增加一个新的复杂因素。链尾必须回到完整泳。

单次训练闭环

步骤做法
E1 基线2×25 米轻松完整泳。记录最明显现象、换气侧、频率、划次、问题何时出现。
E2 一个诊断测试呼吸管 / 脚蹼 / 侧身打腿 / 单臂 / 夹浮漂，确认环节。
E3 一个主问题例：主问题换气抬头；辅助现象换气时腿分开。不要立刻当成两个独立问题。
E4 1～2 个专项各 2～4 组，10～25 米，动作控制优先。
E5 回完整泳4～6×15～25 米。只留一个提示，例如「头只向侧面转」。
E6 再专项→完整优先 D-I09：25 米分解 + 25 米完整。
E7 最终复测4×25 米完整泳。前两组允许提示，后两组尽量不提示。
E8 判断改善则巩固再加距离；专项好完整泳不好 → 迁移（D-I04 / D-I09 / D-E01）；完全不改善 → 重诊上游；更严重代偿 → 降难度或退阶。

进阶规则与退阶信号

F进阶规则
F1同一里程碑至少两次训练稳定出现。避免把偶然成功当成掌握。
F2先增加稳定次数，再增加距离。先多个稳定 25 米，再考虑 50 米。
F3距离增加以后动作崩掉，缩短单组。不是继续硬撑。
F4分解会做但完整泳不会，不通过。必须完成迁移。
F5换气先建立一个稳定侧，再补弱侧。最终左右都能换，不是强制始终三划一换。
F6先动作质量，后速度。速度增加以后，错误动作通常会被放大。

不同训练目标的重点

目标优先顺序 / 重点
轻松连续游呼吸 > 身体平衡 > 换气 > 放松划水 > 连续节奏
长距离线型、稳定抱水、合理划频、控制打腿消耗、双侧换气、技术耐力、配速
短距离更积极打腿、较高划频、快速抱水、连续推进、快速移臂、减少换气造成的速度损失
开放水域左右换气、D-OW01 抬眼观察、直线游、绕标、变速、不同换气时机、水中安全

呼吸控制安全说明

3-5-7、限制换气、Blowout 类练习的目标是呼吸控制和技术保持，不是比谁憋气久。

禁止：训练前过度换气；长时间水下屏气；单独进行憋气训练；把水下打腿做成距离挑战。

出现头晕、视野异常、意识模糊、明显胸闷、异常气短：立即停止。

专项练习不是终点，回到完整自由泳后仍然改善，才算真正学会。

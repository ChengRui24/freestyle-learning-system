四泳姿教学

四式共用的学习路径和每个模块的连贯口令。口诀与练习、分类纠错、技术要点已经并入各式自己的册子。

一节课怎么排见 课程安排。体系依据见 USMS 汇总。

练习前 已会呼气、漂浮和回站；在有救生保障的泳池练习，不独自下水。不适先停，不强憋。意外入水见 水中自救。

通用说明与基础入口

用法分解找动作，过渡接衔接，连贯看节奏。每轮改一个点，再回原动作检验；练习量以质量和通气为准。

环境陆上 → 半陆半水 → 水中固定支撑 → 水中有辅助 → 水中独立。按实际支撑归类，不适用的阶段可跳过。

条件确认路线净空和停止点；不会自主退出时不做独立练习。托扶须由懂得方法的人实施，浮具不等于救生装备；脚蹼、呼吸管先学会使用。普通泳道线不作承重支撑。

计数爬泳、仰泳“一划”指单臂一次；蛙泳、蝶泳指双臂同步一周期。呼吸节拍是练法，不是人人相同的通过标准。

范围供已有基础水性的教练和练习者备课、复习；公开资料综合编写，并非官方统一教案。本文不含竞技出发、转身、长潜和开放水域教学。

呼气俯漂与回站仰漂起游与停止
基础提示

先确认任务

看清起点、终点与扶点，约定停止信号。

入水呼气

浅水站稳吸气，脸入水轻吐；需要气就恢复，不一口强吹尽。

俯漂回站

先在浅水有扶助练习：收膝，双手轻压水，脚底落稳再站起；练会后才减扶。

起游与停止

沿清空路线轻蹬向前，到预定点提前结束；不冲向池壁。

先停再判断

呛咳、恐慌、头晕、疼痛或动作失控时先恢复安全；持续异常不继续加量，必要时求助。

通用路径

每一式先按部位拆成模块：腿、手、手与呼吸、完整配合；仰泳先有基础，蝶泳先有身体波动，蛙泳在完整配合之后再分平蛙和波蛙。

每个模块都按同一序走：分解看要点，过渡记衔接，连贯练节奏。分解先把一个动作做对，过渡把两段接起来，连贯用一句口令把整个模块带起来。

练习环境按支撑减少推进：陆上模仿 → 半陆半水 → 水中固定支撑 → 水中有辅助 → 水中独立完成。不适用的阶段可以跳过，不会自主退出时不做独立练习。

一个模块算不算过，看 课程安排 的通过条件：可重复、可控制、没有明显新代偿、能带回完整泳姿。

连贯口令

每个模块一句。点模块名进该式的课堂教学，看分解、过渡和完整练习。

爬泳（自由泳）

  1. 爬泳腿下打接上抬，左右交替不停；髋先带腿，脚踝顺势跟随。
  2. 爬泳手肩前入水，前臂抱水，向后划推，放松移臂；两手接续，前方不死等。
  3. 爬泳手与呼吸左划时吐气，右划时向右短吸，脸回水后接续。；同样练左侧；不为凑划数少吸气。
  4. 爬泳完整配合肩前入水，掌臂后推；随划转身，侧向快吸；双腿轻快交替，脸先回水。

仰泳

  1. 仰泳基础头颈放平，保持通气；需要结束时，收腿回站。
  2. 仰泳腿下摆回位，上踢鞭水；左右交替，踝松，不向外蹬。
  3. 仰泳手小指入水，沉手抱水，向脚推水，放松摆回；左右交替，头不追手。
  4. 仰泳完整配合头稳身转，两手轮换；双腿小幅不停，呼吸有节奏。

蝶泳

  1. 蝶泳身体波动身体向前，波由躯干传到双脚；幅度够用，头颈不甩。
  2. 蝶泳腿髋带腿回摆，脚背接着鞭水；双腿同步，波小而不断。
  3. 蝶泳手双手同入、同抱、同推、同回；向后划水，向前放松移臂。
  4. 蝶泳手与呼吸随划起胸，低位吸气；移臂时脸先回水，双手随后入水。
  5. 蝶泳完整配合手入一踢，推末二踢；移臂不停，脸先于手回水，接下一轮。

蛙泳

  1. 蛙泳腿脚跟回收，勾脚外翻；向后蹬夹，并腿伸长；动作连贯，不漏翻脚。
  2. 蛙泳手外划找水，抱水内收，快速前伸；不划到腰后再回臂。
  3. 蛙泳手与呼吸外划找水，抱水起胸短吸；手前伸、头回水，水下有节奏吐气。
  4. 蛙泳完整配合抱水短吸，前伸收翻；后蹬夹拢，伸长后接下一划。
  5. 平蛙进阶低位吸气，快速前伸；紧凑收翻，后蹬恢复平直。
  6. 波蛙进阶抱水前起短吸，手前送、头回水；紧凑收翻，后蹬恢复流线型。

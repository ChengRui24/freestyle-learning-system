术语

英文缩写和术语

保留产品官方英文名、技术名词缩写。

高肘抱水（EVF）

EVF = Early Vertical Forearm。抱水早期让前臂尽快形成有效受力面；不是把肘抬得越高越好。

单次划水距离（DPS）

DPS = Distance Per Stroke，每次划水对应的前进距离。计数口径可能不同，也不是越大越好。

跨中线（crossover）

自由泳入水或前伸时，手越过身体纵向中线，常伴随身体摆动或划水绕行。

导向小鳍（skeg）

类似冲浪板的小鳍；用于放大横向偏航阻力，提示入水和前伸路线。

原理

版型、绑带、偏心设计会影响什么？

1. 水阻不只看板面大小

简化看，水动力可写成 F ≈ ½ρ·C·A·v²。A 是受水面积，v 是手与水的相对速度，C 与版型、角度和流动状态有关。板面越大，潜在水阻通常越高，但手速和板面角度同样重要。

大板还会改变手速、划频和划水时序，因此实际负荷不会按板面面积线性增加。

2. 技术反馈主要来自力矩和约束

ISO 的受力中心偏离手掌中心，会产生转动力矩 τ ≈ r × F；Freestyler 的导向小鳍会在手偏航时增加侧向阻力；Agility 依靠持续掌压保持贴合；Fulcrum 则直接限制腕—前臂几何关系。

这些产品主要通过动作约束提供反馈，不只是增加水阻。

研究支持划手掌会改变 DPS、划频、划水时序和协调方式；未找到这 6 款产品的独立直接对照试验。以下差异主要依据官方结构和一般水动力、运动控制原理。

对比

相似产品对比

Manta 对比 Agility

Manta：增加水阻，训练较大负荷下的完整拉水。

Agility：放大掌压中断，板面偏移或掉落就是反馈。

力量 / DPS → Manta；抱水 / 掌压反馈 → Agility。

Agility 对比 ISO

Agility：看是否持续压住水。

ISO：看压力偏向哪一侧、是否过度扫水。

基础反馈 → Agility；精细掌压 → ISO。

Agility 对比 Freestyler

Agility：掌压和抱水连续性。

Freestyler：入水、前伸方向和跨中线。

抓不到水 → Agility；手总走歪 → Freestyler。

Forearm Fulcrum 对比 Bolster

Fulcrum：姿态约束，几乎不加阻力。

Bolster：姿态约束 + 明显水阻。

学习高肘抱水 → Fulcrum；带负荷巩固 → Bolster。

说法证据判断说明
划手掌可增加单次划水距离，并改变划频与划水时序较强多项研究观察到 DPS 增加、划频下降或协调变化；结果受板面、速度和训练任务影响。
大面积一定等于更高训练负荷条件成立大板面提高潜在水动力，但也会改变手速和划频；同速条件下，不一定提高推进力或机械功。
Manta / Agility 能“更安全地”进行力量训练不宜作安全保证没有找到针对 Manta / Agility 的肩部安全试验。
ISO 能隔离指定肌群证据不足非对称板面会改变压力和力矩；没有 ISO 专项 EMG 研究验证肌群隔离。
Freestyler / Fulcrum 可减少肩部压力或预防肩伤不能作临床结论纠正跨中线或错误抱水可能改善力学，但划手掌使用过量也会增加肩部应力。
Fulcrum / Bolster 能帮助学习高肘抱水（EVF）机制合理结构上可限制折腕、强化前臂参与；缺少 FINIS 产品的独立对照试验。
器材练习应围绕训练目标调整尺寸、频率与使用时机较强2023 年研究将划手掌和脚蹼视为任务约束；尺寸、频率和使用时机应按训练目标调整。
肩部：Tech Sheet 中“降低 / 预防肩部压力”等表述不等于伤病预防保证。有肩痛或使用后疼痛时，应减少或停止器材负荷。
